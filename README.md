# 🤖 Daily Quotes Telegram Bot

A Telegram bot built using **Node.js** and **Telegraf** that delivers motivational quotes, supports user subscriptions, runs scheduled jobs, and handles custom commands.

---

## 🚀 Features

- 🌅 Welcome message with bot commands  
- 💡 Fetches random quotes from **ZenQuotes API**  
- ⏰ Sends daily quotes automatically using cron jobs  
- 🔔 Subscribe / Unsubscribe to daily quotes  
- 📂 Custom command to fetch Java code from GitHub  
- 👍 Responds to stickers and greetings  
- 🔐 Secure environment variable handling with `dotenv`  

---

## 🛠️ Tech Stack

- Node.js  
- Telegraf  
- Axios  
- node-cron  
- dotenv  

---

## ⚙️ How to Set Up

### 1️⃣ Create a Telegram Bot
1. Open Telegram and search for **BotFather**
2. Run `/start`
3. Run `/newbot` and follow the instructions
4. Copy the **Bot Token**
